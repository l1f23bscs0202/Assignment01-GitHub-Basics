# Sum of the First 50 Natural Numbers

This C++ program calculates the sum of the first 50 natural numbers using two methods:

1. Using a loop: A `for` loop adds all natural numbers from 1 to 50.
2. Using a formula: The formula `n * (n + 1) / 2` is used, where `n = 50`.

Both methods calculate the sum and display their results.

# Source Code

The C++ program is saved in `main.cpp`.

# Output


Sum using loop = 1275
Sum using formula = 1275


# Conclusion

Both methods produce the same result: 1275.
